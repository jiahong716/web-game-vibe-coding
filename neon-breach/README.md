# NEON BREACH

一款以 Three.js 製作的瀏覽器第一人稱射擊原型：在霓虹訓練場中移動、瞄準失控守衛並在倒數結束前存活。

## 操作方式

- `W A S D`：移動
- 滑鼠移動：轉動視角
- 按住滑鼠右鍵：瞄準（縮小視野、移動速度降低）
- 滑鼠左鍵：射擊準星指向的守衛
- `Esc`：暫停或繼續

## 執行

直接用瀏覽器開啟 `index.html`。遊戲使用 CDN 載入 Three.js，因此首次執行需要網路連線。

## 玩法

- 撐過 60 秒或擊落全部守衛即可完成模擬。
- 守衛接近玩家時會造成傷害。
- 生命值歸零則模擬失敗。

## 素材與授權

場景與模型由程式即時建立，沒有外部圖像或音效素材；場景使用圓角建築、柔和圓形地面標記與平滑球形守衛。Three.js 使用 MIT License，透過 jsDelivr CDN 載入。
